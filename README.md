# Classify-of-Cats-and-Dogs
Projeto: Classificação de Imagens com Transfer Learning (Google Cloud) * Desenvolvimento de um modelo de classificação binária (cães vs. gatos) utilizando a técnica de Transfer Learning.  Implementação de estratégias de Extração de Recursos  e Ajuste Fino para otimizar a precisão do modelo.  Utilização do TensorFlow/Keras no Google Cloud.
